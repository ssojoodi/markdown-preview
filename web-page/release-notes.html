v.20260915

Version 2026.9.15
Build 1 · macOS 13+

Link to this release

Markdown previews, editing, and Quick Look setup

Read Markdown in Finder, edit documents in the app, and convert rich text to Markdown.

01

Preview Markdown

  • View Markdown files in Finder with the Space bar, or open them in the app.
  • Read headings, nested lists, tables, links, blockquotes, and code blocks with formatted text.
  • View Mermaid diagrams and local images alongside your documents.
02

Create and edit

  • Create a new Markdown file or edit an existing document.
  • Convert pasted rich text to Markdown, including headings, bold and italic text, lists, tables, links, and code.
  • Choose Save, Discard, or Cancel when closing a document with unsaved edits.
03

Setup and installation

  • Follow the setup screen to enable Quick Look and save a sample document for testing.
  • Reopen setup from the advanced controls. Setup completion is remembered for each release.
  • Install from a signed and notarized DMG.
